# Medieval Manager

Консольная пошаговая игра-менеджер средневекового поселения на C# (.NET 10).

Управляйте деревней: следите за едой, стройте здания, сажайте рабочих, нанимайте армию,
торгуйте и ходите в рейды. Сюжет разворачивается по дням: нашествие кочевников,
сбор войска для лорда и финальный крестовый поход.

## Возможности

- **Экономика**: ресурсы (золото, еда, сталь, лошади), здания (поместье/кузница/конюшня),
  рабочие из населения, иммиграция при достатке еды, голод при нехватке.
- **Армия**: ополчение, пехота, кавалерия — у каждого свои статы, стоимость и роль.
  Найм ограничен свободным населением; платное восполнение потерь.
- **Интерактивный бой по часам**: обе стороны показаны по типам войск с численностью
  и моралью; конницу можно ставить в резерв и вводить в любой момент (или она выходит
  автоматически при окружении). Окружение зависит от превосходства конницы.
- **Торговля**: цены проседают при демпинге и восстанавливаются с приходом каравана.
- **Сюжет**: события привязаны к случайным дням в окнах (реиграбельность) —
  нашествие, сбор войска, крестовый поход.


## Запуск

```bash
dotnet run
```

Требуется .NET SDK 10.0+.

## Настройка баланса

Все игровые числа (статы юнитов, экономика, составы врагов, окна сюжетных событий,
поведение боя) собраны в статическом классе `Balance` —
меняйте их там, не трогая логику.
